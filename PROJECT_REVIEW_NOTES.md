\# AuraGen Project Review Notes



\## Project Title



AuraGen: Self-Healing Generative UI via Cognitive Load



\## Main Idea



AuraGen monitors user interaction patterns and adapts the user interface

according to the estimated cognitive load.



\## Problem



Static forms do not respond to user hesitation or interaction difficulty.



\## Solution



AuraGen uses interaction telemetry and a decision engine to select an

appropriate interface adaptation.



\## Main Modules



1\. Financial Information Form

2\. Mouse Movement Tracking

3\. Mouse Movement History

4\. Movement Analysis

5\. Hesitation Detection

6\. Active Field Tracking

7\. Field Interaction Counters

8\. Friction Score

9\. Cognitive Load Score

10\. Self-Healing UI

11\. Simplified Form Mode

12\. AuraGen Decision Engine



\## Decision Engine Actions



\- NORMAL\_MODE

\- SHOW\_GUIDANCE

\- SIMPLIFY\_FORM



\## Project Outcome



The prototype demonstrates how a user interface can respond dynamically

to user interaction difficulty.



\## Future Scope



\- Machine learning-based cognitive load prediction

\- Large Language Model integration

\- WebSocket telemetry streaming

\- Database integration

\- Personalized UI adaptation

\- Accessibility-aware interface adaptation
